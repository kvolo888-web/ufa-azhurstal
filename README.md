## ✨ Возможности

- **Каталог** — мангалы, кочерги, ворота, калитки, заборы, качели, каминные
  наборы, кровати, вешалки; фото, описание, стартовая цена.
- **Конструктор цены** — у каждого изделия: форма/размеры, доп. элементы,
  количество (секции забора, метры, комплектация). Цена пересчитывается мгновенно.
  - Заборы: количество секций × размер × рисунок заполнения.
  - Мангалы и кровати: форма корпуса/изголовья + габариты.
- **Корзина** — добавление, изменение количества, удаление, итог;
  хранится в браузере (localStorage), не пропадает при перезагрузке.
- **Оформление заказа** — контакты → доставка (5 вариантов) → **оплата**
  (карта онлайн, СБП, безнал для юрлиц, при получении) → номер заказа.
- **Вкладка «О нас»** — реквизиты (копируются одной кнопкой), контакты,
  мини-карта проезда, видео о работах, контакты для поставщиков металла,
  оборудования и партнёров.
- **Вкладка «Отзывы»** — рейтинг с разбивкой по звёздам + рабочая форма
  добавления отзыва.
- **Вкладка «Доставка»** — способы, зоны, монтаж под ключ, FAQ.
- **Анимации** — летящие искры, scroll-reveal, hover-эффекты, тосты;
  уважает `prefers-reduced-motion`.

## 🚀 Быстрый старт

Нужен **Node.js 18+** ([nodejs.org](https://nodejs.org), берите LTS). Проверка:

```bash
node -v   # v18 или новее
npm -v
```

Запуск:

```bash
npm install    # один раз — ставит зависимости
npm run dev    # режим разработки → http://localhost:5173
```

Правки подхватываются на лету — сохраняете файл, страница обновляется сама.

## 📦 Сборка и публикация

```bash
npm run build    # готовый сайт → папка dist/
npm run preview  # посмотреть собранную версию локально
```

Куда положить `dist/`:

| Хостинг | Как |
|---|---|
| **GitHub Pages** | автоматически (см. ниже) |
| Netlify / Vercel | перетащить папку `dist/` в веб-интерфейсе |
| Timeweb / Beget | загрузить файлы `dist/` в корень сайта |
| Свой Nginx / Apache | скопировать `dist/` в каталог сайта |

## 🐙 Публикация на GitHub

### Командами (рекомендуется)

1. Создайте пустой репозиторий: [github.com/new](https://github.com/new),
   имя — например `ufa-azhurstal`, без галочки «Add README».
2. В папке проекта:

```bash
git init
git add .
git commit -m "Уфа-Ажурсталь: лендинг кузницы"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ufa-azhurstal.git
git push -u origin main
```

3. В репозитории: **Settings → Pages → Source: GitHub Actions**.
   Через пару минут сайт оживёт по адресу
   `https://ВАШ_ЛОГИН.github.io/ufa-azhurstal/`,
   а ссылка на код будет `https://github.com/ВАШ_ЛОГИН/ufa-azhurstal`.

Дальше достаточно `git push` — workflow `.github/workflows/deploy.yml`
сам пересоберёт и обновит сайт.

### Что попадает в репозиторий

`git add .` забирает всё, `.gitignore` исключает лишнее:

| Загружается | Зачем |
|---|---|
| `src/` | исходный код: компоненты, каталог, цены, корзина |
| `index.html`, `vite.config.js`, `tsconfig.json` | настройки сборки |
| `package.json`, `package-lock.json` | зависимости (GitHub поставит их сам) |
| `.github/workflows/deploy.yml` | автопубликация на GitHub Pages |
| `.gitignore`, `README.md` | служебные файлы |

**Не попадают:** `node_modules/` и `dist/` — они генерируются командами.

### Вход на GitHub

Пароли больше не работают — нужен токен:
**GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)**
→ Generate → галочка **repo** → скопировать и вводить вместо пароля при `git push`.

### Если проект создан в среде Qwen

Прямого подключения GitHub в среде нет — в два шага:
1. Скачайте архив проекта из интерфейса Qwen и распакуйте в папку.
2. Отправьте на GitHub командами выше (или перетащите файлы мышкой через
   *«uploading an existing file»* в репозитории — всё, кроме `node_modules` и `dist`).

## ✏️ Как редактировать контент

Весь контент — в данных, компоненты трогать не нужно.

| Что | Файл |
|---|---|
| Товары, цены, конфигуратор | `src/data/catalog.ts` |
| Телефон, e-mail, адрес | `src/data/content.ts` → `CONTACTS` |
| Реквизиты | `src/data/content.ts` → `REQUISITES` |
| Отзывы | `src/data/content.ts` → `INITIAL_REVIEWS` |
| Видео о работах | `src/data/content.ts` → `VIDEOS` |
| Способы доставки и FAQ | `src/data/content.ts` → `DELIVERY_*` |
| Контакты поставщикам | `src/data/content.ts` → `PARTNERS` |
| Логотип | `src/components/Logo.tsx` |

### Расширить линейку товаров

Добавьте объект в массив `PRODUCTS` в `src/data/catalog.ts` —
карточка, конфигуратор и корзина подхватят товар автоматически:

```ts
{
  id: "urn",
  name: "Урна «Гербовая»",
  category: "decor",            // новая категория — допишите её в CATEGORIES
  basePrice: 9800,
  image: "https://…/photo.jpg", // фото 4:3 (1024×768); при ошибке — фирменная заглушка
  description: "Уличная урна с гербовым рисунком и съёмным ведром.",
  options: [
    // 1) select — выбор одного варианта (форма, размер)
    { id: "volume", label: "Объём", kind: "select", per: "base", values: [
        { id: "40", label: "40 л", dims: "В 500 × Ø 350", price: 0 },
        { id: "60", label: "60 л", dims: "В 600 × Ø 400", price: 1400 },
    ]},
    // 2) multi — мультивыбор элементов, доплата за каждый
    { id: "extra", label: "Дополнительно", kind: "multi", values: [
        { id: "lid", label: "Крышка-зонт", price: 1800 },
        { id: "crest", label: "Герб города", price: 2500 },
    ]},
    // 3) number — количество: доплата умножается на значение
    { id: "anchors", label: "Анкерные шпильки", kind: "number",
      min: 0, max: 8, step: 1, unit: "шт.", per: "unit",
      values: [{ id: "a", label: "Шпилька М12", price: 150 }] },
  ],
}
```

`per: "base"` — доплата разовая, `per: "unit"` — умножается на количество.

## 🗂 Структура проекта

```
src/
  App.tsx                    — вкладки, модалки, тосты
  data/catalog.ts            — каталог + формула расчёта цен
  data/content.ts            — контакты, реквизиты, отзывы, доставка, видео
  context/CartContext.tsx    — корзина (localStorage) + уведомления
  hooks/useReveal.ts         — появление секций при скролле
  components/
    Header.tsx / Footer.tsx  — шапка (лого, телефон, почта) и подвал
    Home.tsx                 — главная: искры, каталог, индивидуальный заказ
    ConfiguratorModal.tsx    — конфигуратор изделия с живым пересчётом цены
    CartDrawer.tsx           — корзина: доставка, оплата, подтверждение
    About.tsx                — о нас, реквизиты, видео, поставщикам
    Reviews.tsx              — отзывы + форма
    Delivery.tsx             — способы доставки, монтаж, FAQ
    Logo.tsx                 — фирменный SVG-знак (подкова с искрой)
```

## ❓ FAQ

**Где заменить телефоны и почту?** — `src/data/content.ts`, объект `CONTACTS`
(и подвал подтянется автоматически).

**Как сделать реальную оплату?** — сейчас шаг оплаты имитируется. Подключите
ЮKassa/Робокассу в `src/components/CartDrawer.tsx` (функция `placeOrder` —
туда же добавьте отправку заказа на почту или в Telegram-бота).

**Картинки не грузятся?** — у каждой карточки есть фирменная SVG-заглушка;
фото можно заменить своими, положив их в `public/images/` и указав путь
`/images/фото.jpg` в поле `image`.

**Как привязать свой домен?** — на GitHub Pages: Settings → Pages →
Custom domain → `ufa-azhurstal.ru`, у регистратора домена добавьте
A-записи GitHub (`185.199.108.153` и др.).
